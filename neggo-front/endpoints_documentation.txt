# Neggo API Endpoints Documentation

This document lists the endpoints called by the frontend and the expected structure of the `data` field in the response.

## Standard Response Format
All responses from the backend should follow this structure:
```json
{
  "success": boolean,
  "error": string | false,
  "data": any
}
```

---

## 1. Authentication

### POST `/auth/login`
- **Purpose**: Authenticate user.
- **Payload**: `{ email, password }`
- **Data on Success**: 
  ```json
  {
    "id": "user_uuid",
    "token": "session_jwt_string",
    "firebaseToken": "custom_firebase_token_for_chat"
  }
  ```

### POST `/auth/register`
- **Purpose**: Create a new account.
- **Payload**: `{ email, password, name, phone }`
- **Data on Success**: `null` (Redirects to login page)

---

## 2. Advertisements (Offers)

### GET `/ads`
- **Purpose**: Fetch all active ads.
- **Data on Success**: `Ad[]` (List of Ad objects)

### GET `/ads/:id`
- **Purpose**: Fetch details of a specific ad.
- **Data on Success**: `Ad` (Single Ad object)

### POST `/ads`
- **Purpose**: Create a new ad.
- **Payload**: `Partial<Ad>`
- **Data on Success**: `Ad` (The created Ad object)

---

## 3. Chat System (Now integrated into Backend)

### GET `/chats`
- **Purpose**: Fetch all active conversations for the user.
- **Data on Success**: `ChatListItem[]`

### GET `/chats/:id/messages`
- **Purpose**: Fetch messages for a specific conversation.
- **Data on Success**: `Message[]`

### POST `/chats/:id/messages`
- **Purpose**: Send a message.
- **Payload**: `{ text: string }`
- **Data on Success**: `Message`

---

## 4. Plans and Subscriptions

### GET `/plans`
- **Purpose**: Fetch all available subscription plans.
- **Data on Success**: `Plan[]`

### POST `/plans/:id/buy`
- **Purpose**: Purchase a subscription plan.
- **Data on Success**: `{ success: true }`

---

## 5. Boosts

### POST `/ads/:id/boost`
- **Purpose**: Purchase a visibility boost for a specific ad.
- **Data on Success**: `{ success: true }`

---

## 6. Profile

### GET `/profile`
- **Purpose**: Fetch current user profile details.
- **Data on Success**: `User` (User profile object)

---

## 4. Plans & Billing

### GET `/plans`
- **Purpose**: Fetch available subscription plans.
- **Data on Success**: `Plan[]` (List of Plan objects)

---

## Data Models

### Ad Object
```json
{
  "id": "string",
  "title": "string",
  "description": "string",
  "price": "number | 'negotiable'",
  "isNational": "boolean",
  "locations": [{ "city": "string", "state": "string" }],
  "type": "'product' | 'service'",
  "category": "string",
  "images": ["string"],
  "sellerId": "string",
  "condition": "'new' | 'used'",
  "serviceType": "'remote' | 'in_person'",
  "isBoosted": "boolean",
  "status": "'active' | 'sold' | 'cancelled'",
  "createdAt": "ISO_DATE_STRING"
}
```

### User Object
```json
{
  "id": "string",
  "name": "string",
  "photoUrl": "string",
  "rating": "number",
  "isPro": "boolean",
  "phone": "string"
}
```

### Plan Object
```json
{
  "id": "string",
  "name": "string",
  "price": "number",
  "adLimit": "number",
  "benefits": ["string"]
}
```
